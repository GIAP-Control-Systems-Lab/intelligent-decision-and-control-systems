Controller workspace:
  All controller-specific parameters, states and algorithms are isolated
  inside config/controller/.

Fixed controller runtime interface:
  Inputs : T_ref, T_error, T_meas
  Output : duty_cycle

Portable startup:
  Every runtime path is derived from the project root.
  No user-specific or computer-specific absolute paths are stored.
  results/ is created automatically when required.
  The same notebooks are used in VS Code/Jupyter and Google Colab.
  No MATLAB, Simulink, .fis, or .mat dependency is required.
